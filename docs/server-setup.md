# Подготовка развёртывания

- Образ: `ghcr.io/matveydd/devops-ci-app`
- Тег: полный SHA проверенного коммита из `main`
- Порт контейнера: `5000`
- Проверка состояния: `GET /health`
- Для загрузки приватного пакета нужен доступ GHCR на чтение. Не хранить токен в репозитории.

Перед Ansible-развёртыванием сюда нужно записать SHA опубликованной версии и параметры целевой VM.
